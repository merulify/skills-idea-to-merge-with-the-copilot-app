# Mona Bookmark Roadmap
A focused roadmap for improving usability, reliability, and data safety in Mona’s Bookmark Manager.

| Area | Item | Type | Priority |
| --- | --- | --- | --- |
| Discovery | Search & filter bookmarks | 🚀 | High |
| Editing | Edit an existing bookmark | 🚀 | High |
| Organization | Tags or folders for grouping | 🚀 | Medium |
| Portability | Import/export bookmarks | 🚀 | Medium |
| Data integrity | Duplicate slugs on re-add | 🐞 | Medium |
| Validation | Empty-URL validation gaps | 🐞 | High |
| Persistence risk | Bookmarks lost if localStorage is cleared | 🐞 | High |

## 🚀 Planned features
- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: high
- 🏷️ Tags or folders — priority: medium
- 📦 Import/export bookmarks — priority: medium

## 🐞 Known bugs & risks
- 🐞 Duplicate slugs on re-add — priority: medium
- ⚠️ Empty-URL validation gaps — priority: high
- 💾 Bookmarks lost when localStorage is cleared — priority: high
